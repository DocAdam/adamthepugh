# Documentation tooling and automation

**Context:** Meta, Senior Documentation Engineer, 2025–2026<br />
**Audience:** Documentation contributors and internal operating partners

Repeated documentation work included change review, stale-content checks, media lookup, submission checks, and task setup. I treated these as documentation problems first. I confirmed the manual workflow, defined the stable part, and then used AI-assisted development to build practical tools and checks.

## My role

I identified the problems, designed the workflows, directed AI-assisted implementation, checked the results, and maintained the tools.

## Representative work

- A wiki-change comparison dashboard that supported manual reconciliation of content changes.
- An image-lookup tool for media stored in inconsistent CMS locations.
- Review and submission checks that applied standards from real editorial feedback.
- Workflow support for task setup, content synchronization, and change triage.
