# Writing and Content Strategy

The strongest writing work on this site is not a stack of detached samples. It is the judgment behind a useful page: choosing the right form, explaining the right amount, and maintaining the content as the system changes.

<pre className="system-flow">user intent

    ▼

## Representative work

| Content type | What good looks like |
| --- | --- |
| Customer and change communication | Explain what changed, why it matters, and what the reader needs to do next. |
| Task documentation | Sequence the work clearly, with scoped notes and warnings where they affect the outcome. |
| Reference content | Use consistent labels and definitions so readers can find the answer quickly. |
| Feature explanations | Give enough context to understand behavior without burying the useful detail. |
| Content strategy | Make page-type, editing, standards, and information-architecture decisions across larger systems. |
